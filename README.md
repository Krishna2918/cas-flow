# CAS Flow

Interactive product map of the College Admissions System — recruiter QR through to the student portal.

Pan and zoom the diagram, click a capability for connections, or walk a path (walk-in, agent referral, remote enrol, batch to placement).

Built with TanStack Start, React, and Tailwind.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Krishna2918/cas-flow)

## Deploy on Vercel

1. Open the button above, or in Vercel: **Add New → Project → Import** `Krishna2918/cas-flow`.
2. Leave the build command as `npm run build`.
3. After the first deploy, open **Settings → Deployment Protection** and turn **Vercel Authentication** off so the link is public.

Hobby teams protect new projects with a Vercel login wall by default. The map itself has no sign-in.

## Local

```sh
npm install
npm run dev
```
